# Replay Hard-Failure Evidence

This package demonstrates structured hard-failure handling during deterministic LLM-free replay.

## Generation

Generated by a real Playwright replay of `lookup_savings_balance` version `1.0.1` against the deterministic application-error demo scenario. Replay detects the application failure and stops without improvising recovery through an LLM.

## Expected result

- Status: `failure`
- Code: `APPLICATION_ERROR`
- Failing step: `enter-member-search`
- Steps executed: `0`
- Screenshot evidence captured

## Important files

- `run.json` — sanitized replay metadata
- `events.jsonl` — structured failure and runtime events
- `result.json` — typed `APPLICATION_ERROR` terminal result
- `screenshots/` — synthetic-fixture failure screenshot
- `SHA256SUMS.txt` — expected SHA-256 hashes for the frozen package

Temporary traces, raw browser state, and unrelated runtime artifacts are intentionally excluded.

## Integrity

`SHA256SUMS.txt` contains the expected SHA-256 hashes for the frozen files. Recompute the hashes locally and compare them with the manifest before relying on the package.
