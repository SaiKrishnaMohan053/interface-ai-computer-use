# Replay Business-Outcome Evidence

This package demonstrates deterministic handling of an expected business outcome during LLM-free replay.

## Generation

Generated by a real Playwright replay of the persisted `lookup_savings_balance` capability against the unknown-member demo scenario. Replay does not use an LLM.

## Expected result

- Capability: `lookup_savings_balance`
- Version: `1.0.1`
- Status: `business_outcome`
- Code: `MEMBER_NOT_FOUND`
- Detection point: `submit-member-search`

`MEMBER_NOT_FOUND` is returned as a typed business outcome rather than being treated as a generic runtime failure.

## Important files

- `run.json` — sanitized replay metadata
- `events.jsonl` — structured replay and business-outcome events
- `result.json` — typed `MEMBER_NOT_FOUND` terminal result
- `SHA256SUMS.txt` — expected SHA-256 hashes for the frozen package

Invocation input values and unrelated runtime artifacts are intentionally excluded.

## Integrity

`SHA256SUMS.txt` contains the expected SHA-256 hashes for the frozen files. Recompute the hashes locally and compare them with the manifest before relying on the package.
