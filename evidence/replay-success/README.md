# Replay Success Evidence

This package demonstrates deterministic LLM-free replay of the saved `lookup_savings_balance` capability against the local synthetic banking application.

## Generation

Generated by a real Playwright replay of the persisted capability using the normal-success demo scenario. Replay follows the saved artifact and does not use an LLM decision loop.

## Expected result

- Capability: `lookup_savings_balance`
- Version: `1.0.0`
- Status: `success`
- Steps executed: `4`
- Output: `savingsBalance = $12,840.50`

Invocation input values are intentionally omitted from reviewer evidence; validated input names are recorded without persisting sensitive values.

## Important files

- `run.json` — sanitized replay metadata
- `events.jsonl` — structured replay events
- `result.json` — terminal success result and extracted output
- `SHA256SUMS.txt` — expected SHA-256 hashes for the frozen package

Temporary traces and unrelated runtime artifacts are intentionally excluded.

## Integrity

`SHA256SUMS.txt` contains the expected SHA-256 hashes for the frozen files. Recompute the hashes locally and compare them with the manifest before relying on the package.
